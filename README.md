# Scan-Old-Date

Локальный сканер старых фотографий: обнаруживает визуальные штампы даты, распознаёт дату и записывает её в метаданные изображения.

## Возможности

- Рекурсивное сканирование выбранных папок.
- Сохранение исходных файлов без изменений до подтверждения пользователя.
- Чтение существующей EXIF-даты для сравнения; распознанная по штампу дата отображается отдельно и не подменяется значением EXIF.
- Поиск компактных групп ярко-жёлтых символов по выравниванию строки/столбца и положению у края кадра; для белых, красных и выцветших штампов предусмотрен ограниченный поиск в нижних углах и боковых областях.
- OCR через Tesseract с поворотами фрагментов на 90°/270°, усилением контраста и выделением жёлто-оранжевых символов.
- Диагностический просмотр исходной фотографии с прямоугольниками всех областей, переданных OCR, и текстом распознавания для каждой области.
- Опциональный YOLO-детектор; дополнительная проверка сложных случаев локальной vision-моделью Ollama.
- Проверка календарной корректности, оценка уверенности OCR и ручная коррекция даты в GUI (формат `YYYY-MM-DD`). В таблице показывается одна дата, а альтернативы и исходный текст доступны в диагностике.
- Запись даты в EXIF и изменение времени файла Windows (оба действия можно отключить).
- SQLite-журнал результатов и операций.
- GUI на PySide6 и CLI для пакетной обработки.

## Принцип работы

1. Сканер находит поддерживаемые изображения.
2. Читает существующие EXIF-метаданные только для справки. Наличие даты в EXIF никогда не отменяет поиск визуального штампа.
3. Детектор сначала группирует ярко-жёлтые компоненты в одну узкую горизонтальную или вертикальную строку штампа. Если такой группы нет, проверяются четыре ограниченные области у краёв фотографии.
4. OCR проверяет локализованный фрагмент, увеличивает его до удобного размера и использует исходную яркость, бинаризацию и узкую маску ярко-жёлтых символов. Вертикальный штамп поворачивается перед распознаванием.
5. Парсер проверяет варианты даты, в том числе дату без пробела перед временем и частую OCR-ошибку, когда косая черта после года читается как цифра.
6. Пользователь проверяет результат: двойной щелчок по строке или кнопка «Показать рамки штампа» открывает фото с прямоугольниками областей OCR. Зелёные рамки содержат кандидатов даты, оранжевые проверены, но не дали даты.
7. Пользователь проверяет дату в формате `YYYY-MM-DD`. Для неоднозначных и низкоуверенных результатов программа отдельно запрашивает подтверждение именно того значения, которое показано в таблице.
8. При применении изменений создаётся резервная копия, записываются EXIF-теги и время файла.

**Важно:** точность зависит от качества скана, типа штампа, разрешения и формата даты. YOLO-модель из проекта pike00 ориентирована преимущественно на оранжевые/красные LED-штампы на фотопечати 4×6 и не должна считаться универсальной. Она подключается как дополнительный детектор, а не как единственный способ поиска.

## Требования

- Windows 10/11 x64
- uv (установщик при отсутствии загрузит его официальным установщиком Astral); uv автоматически установит стандартный CPython 3.12 x64
- ExifTool (рекомендуется для надёжной записи метаданных)
- Tesseract OCR (для локального OCR)
- Ollama с vision-моделью (по умолчанию используется локальный fallback `gemma4:12b`; если Ollama или модель не найдены, fallback пропускается)
- YOLO weights (необязательно)

## Установка

1. Запустите `install.bat`. Если uv отсутствует, скрипт установит его официальным установщиком Astral.
2. Установщик через uv установит обычный CPython 3.12 x64 (не Free-Threading), создаст виртуальное окружение `.venv` и установит зависимости проекта.
3. Установите [ExifTool](https://exiftool.org/) и [Tesseract OCR](https://github.com/UB-Mannheim/tesseract/wiki).
4. Для гибридного распознавания установите [Ollama](https://ollama.com/) и загрузите vision-модель. В конфигурации по умолчанию указана `gemma4:12b`; при необходимости замените её на установленную у вас модель или задайте `ollama.enabled: false`.
5. Настройте `config/settings.yaml`.
6. Запустите `run.bat`.

Зависимости Python управляются через `uv sync`. Установка нативных зависимостей из исходников отключена; если для текущей платформы нет готового wheel, uv завершит установку ошибкой вместо попытки локальной компиляции.

## Первый запуск

По умолчанию приложение работает в режиме Dry Run. Сначала проверьте результаты распознавания, затем включите применение изменений. Исходные изображения не должны перезаписываться без резервной копии.

CLI:

```powershell
python -m scan_old_date.cli "D:\Photos" --dry-run
```

Применить результаты с высокой уверенностью:

```powershell
python -m scan_old_date.cli "D:\Photos" --apply
```

## Настройки

Основные параметры находятся в `config/settings.yaml`. Файл настроек всегда определяется относительно каталога проекта, а не текущей рабочей папки. Пути к ExifTool и Tesseract также можно задать непосредственно в GUI: для каждого инструмента доступны выбор EXE-файла и выбор папки установки. При выборе папки приложение ищет исполняемый файл в её корне и в подпапке `bin`. После изменения нажмите **«Сохранить настройки»**; параметры также сохраняются автоматически перед сканированием.

- порог автоматического принятия (по умолчанию `0.82`);
- расширения файлов;
- пути к ExifTool и Tesseract OCR (EXE, папка установки или команда из PATH);
- параметры Ollama (по умолчанию включён локальный fallback);
- путь к YOLO weights;
- запись EXIF и времени файла;
- резервное копирование.

## Безопасность данных

- Никакие изображения не отправляются во внешние облачные API.
- Ollama вызывается только по локальному адресу, заданному в конфигурации.
- YOLO и OCR выполняются локально.
- Резервные копии создаются до изменения файла.
- Неоднозначные даты отправляются на ручную проверку.
- SQLite хранит историю сканирования и применённых изменений.

## Ограничения текущей версии

Это начальная версия проекта. Распознавание штампов разных производителей и эпох требует проверки на реальной коллекции. Детектор ориентирован на компактные строки символов у края, а не на поиск любых жёлтых объектов на фотографии. Если штамп частично обрезан самой фотографией (например, часть цифр ушла за правый край), приложение не может достоверно восстановить отсутствующие символы. YOLO не включён в комплект весов: пользователь может подключить совместимую модель самостоятельно. Обучение собственной модели и расширенная разметка — отдельный этап.
