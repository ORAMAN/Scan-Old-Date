# Scan-Old-Date

Локальный сканер старых фотографий: обнаруживает визуальные штампы даты, распознаёт дату и записывает её в метаданные изображения.

## Возможности

- Рекурсивное сканирование выбранных папок.
- Сохранение исходных файлов без изменений до подтверждения пользователя.
- Чтение существующих EXIF-дат и защита от их случайной перезаписи.
- Поиск штампов разных цветов и форматов: анализ углов и областей изображения средствами OpenCV.
- OCR через Tesseract; опциональный YOLO-детектор; дополнительная проверка сложных случаев локальной vision-моделью Ollama.
- Проверка календарной корректности, оценка уверенности по OCR confidence и ручная коррекция даты в GUI (формат `YYYY-MM-DD`; неоднозначные варианты показываются через `/`).
- Запись даты в EXIF и изменение времени файла Windows (оба действия можно отключить).
- SQLite-журнал результатов и операций.
- GUI на PySide6 и CLI для пакетной обработки.

## Принцип работы

1. Сканер находит поддерживаемые изображения.
2. Читает существующие EXIF-метаданные. Уже заполненные даты по умолчанию не перезаписываются.
3. Детектор формирует кандидаты областей: углы изображения, цветовые маски и дополнительные области.
4. OCR распознаёт текст. При включённой конфигурации YOLO уточняет область штампа.
5. Парсер проверяет варианты даты и формирует оценку уверенности.
6. Пользователь проверяет результат. Автоматическая запись разрешена только при достижении порога уверенности и отсутствии неоднозначности.
7. При применении изменений создаётся резервная копия, записываются EXIF-теги и время файла.

**Важно:** точность зависит от качества скана, типа штампа, разрешения и формата даты. YOLO-модель из проекта pike00 ориентирована преимущественно на оранжевые/красные LED-штампы на фотопечати 4×6 и не должна считаться универсальной. Она подключается как дополнительный детектор, а не как единственный способ поиска.

## Требования

- Windows 10/11 x64
- Python 3.12 x64 (поддерживаются Python 3.11–3.13 x64)
- ExifTool (рекомендуется для надёжной записи метаданных)
- Tesseract OCR (для локального OCR)
- Ollama с vision-моделью (по умолчанию используется локальный fallback `gemma4:12b`; если Ollama или модель не найдены, fallback пропускается)
- YOLO weights (необязательно)

## Установка

1. Установите Python 3.12 x64 с официального сайта Python. Не используйте 32-bit сборку.
2. Установите [ExifTool](https://exiftool.org/) и [Tesseract OCR](https://github.com/UB-Mannheim/tesseract/wiki).
3. Для гибридного распознавания установите [Ollama](https://ollama.com/) и загрузите vision-модель. В конфигурации по умолчанию указана `gemma4:12b`; при необходимости замените её на установленную у вас модель или задайте `ollama.enabled: false`.
4. Запустите `install.bat`. Установщик использует бинарные wheels для Pillow, OpenCV и PySide6; сборка этих библиотек из исходников не требуется.
5. Настройте `config/settings.yaml`.
6. Запустите `run.bat`.

## Первый запуск

По умолчанию приложение работает в режиме Dry Run. Сначала проверьте результаты распознавания, затем включите применение изменений. Исходные изображения не должны перезаписываться без резервной копии.

CLI:

```powershell
python -m scan_old_date.cli "D:\Photos" --dry-run
```

Применить результаты с высокой уверенностью:

```powershell
python -m scan_old_date.cli "D:\Photos" --apply
```

## Настройки

Основные параметры находятся в `config/settings.yaml`:
- порог автоматического принятия;
- расширения файлов;
- ExifTool и Tesseract;
- параметры Ollama (по умолчанию включён локальный fallback);
- путь к YOLO weights;
- запись EXIF и времени файла;
- резервное копирование.

## Безопасность данных

- Никакие изображения не отправляются во внешние облачные API.
- Ollama вызывается только по локальному адресу, заданному в конфигурации.
- YOLO и OCR выполняются локально.
- Резервные копии создаются до изменения файла.
- Неоднозначные даты отправляются на ручную проверку.
- SQLite хранит историю сканирования и применённых изменений.

## Ограничения текущей версии

Это начальная версия проекта. Распознавание штампов разных производителей и эпох требует проверки на реальной коллекции. YOLO не включён в комплект весов: пользователь может подключить совместимую модель самостоятельно. Обучение собственной модели и расширенная разметка — отдельный этап.
